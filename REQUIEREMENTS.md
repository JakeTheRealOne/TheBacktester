- Features:

### Chart

- Show:
    - candlesticks
    - *setable* indicators used in the strategy
    - *setable* trades
    - equity chart
- Allow to use MOUSE to navigate in the chart
- Update period and data if Ticker, Start date or End date are updated in [Backtesting settings]
- Change view period to 1H 1D 1W 1M YTD ALL
- When "Test" button is clicked: a cursor is created and run at 00:00 that browse all trades and decision of the strategy on the given period

### Backtesting settings

- Ticker
- Start date (default: AEAP)
- End date (default: NOW)
- Candle size (default: 1D)
  [OR] A OHLC dataframe
- Cash (default: 10000$)
- Spread (default: 0.0)
- Commission (...)
- Margin
- TradeOnClose
- Hedging
- ExclusiveOrders
- FinalizeTrades

## Report

A report is generated by finalizing a working strategy

- as HTML first
- as PDF too

A report contains:
    - Base info:
        * Author name
        * Strategy name
        * Strategy description
        * Report generation
        * Strategy code (python)
        * Strategy used indicators
    - Backtest info:
        * Ticker, period, starting cash etc. (see Backtesting settings)
    - Classic Performances:
        * Duration
        * Exposure time [%]
        * Equity final [$]
        * Equity peak [$]
        * Return [%]
        * B&H return [%]
        * Return ann.
        * Volatility ann.
        * CAGR
        * ~~Sharpe ratio~~
        * Sortino ratio
        * Calmar ratio
        * Max. Drawdown
        * Avg. Drawdown
        * Max. Drawdown duration
        * Avg. Drawdown duration
        * # trades
        * Win Rate
        * ...
    - Decisive Performances: (PREMIUM)
        * alpha
        * beta
        * sharp ratio

## Community

- A user save each strategy as a project:
    Project(__author__, __id__, Name, Description, Ticker/FromFile)

- Premade templates:
    - Empty Strategy class
    - Buy and Hold
    - Crossing SMA
    - MACD

- A user can choose strategy privacy (default: private) to share to the community

- A community tab is keeping track of all community strategies (sort by: newest, most profitable, ticker, less drawdown, ...)

- A user profile is made of:
    - Basic info (User(id, username, email, joinedDate, lastActiveDate))
    - Stats (Strategies submitted)
    - Published strategiez

- A starring system for each strategies
